# Systemic Consensing Tool (Widerstandsabfrage)

A modern, real-time web application for inclusive group decision-making using the **Systemic Consensing** method. Instead of voting for a favorite, participants rate their **resistance** (0-10) to each option. The option with the least total resistance wins.

> **🤖 AI-Generated Project**
> This entire project (Frontend, Backend, Database setup, and Design) was generated by **Google DeepMind's Antigravity AI**.

## Features

- **📊 Real-time Voting**: Live updates of results as participants vote.
- **🌓 Dark/Light Mode**: Fully themeable UI.
- **🌍 Internationalization**: Native support for **German** (DE) and **English** (EN).
- **📱 Responsive Design**: Works on meaningful mobile and desktop layouts.
- **🛡️ Admin Dashboard**: 
  - Manage rounds, view detailed stats, and delete data.
  - Access at `/admin` (Default Key: `supersecret`).
- **🙅 Resistance Scale**: 
  - `0`: No Objection (Perfect)
  - `10`: Veto (Cannot accept)

## Tech Stack

- **Frontend**: React, Vite, CSS Variables (Theming).
- **Backend**: Python, FastAPI, SQLModel (SQLAlchemy).
- **Database**: PostgreSQL.
- **Infrastructure**: Docker & Docker Compose.

## 🚀 Getting Started

### Prerequisites
- Docker & Docker Compose

### Running the App

1. Clone the repository.
2. Run the application:
   ```bash
   docker-compose up --build
   ```
3. Open your browser:
   - **Frontend**: [http://localhost:5173](http://localhost:5173)
   - **Backend API**: [http://localhost:8000/docs](http://localhost:8000/docs)
